# Security policy

## Reporting a vulnerability

Please report a vulnerability privately through GitHub: open the [Security tab](https://github.com/vuon9/kho/security) and choose **Report a vulnerability**. Don't open a public issue for it.

Include the kho version (`kho --version`), your OS, and the steps that show the problem. You'll get a reply within 7 days, and a fix or a plan once the report is confirmed.

## Supported versions

Only the latest release gets security fixes.
